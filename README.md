# ChisFlash Beggar Boost

Firmware for the STM32-based Beggar cartridge programmer. It improves ROM write and readback performance and adds faster verification with the ChisFlash FlashGBX plugin.

[Download the firmware](https://github.com/ChisLightyear/ChisFlash-Beggar-Boost/releases/latest)

## Acknowledgments

Thanks to **julpage** and the [beggar_socket](https://github.com/julpage/beggar_socket) contributors for open-sourcing the original programmer. This firmware builds on their project.
